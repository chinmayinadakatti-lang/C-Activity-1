# Activity 1 — C/C++ Development Environment Setup

## Objective

To install and configure a working C/C++ development environment in VS Code for writing, compiling, and running C programs.

## Tools Used

* Visual Studio Code
* Microsoft C/C++ Extension
* MSYS2
* MinGW-w64 (GCC)
* Git
* GitHub

## Compiler

MinGW-w64 GCC through MSYS2 (UCRT64)

Compiler PATH:
`C:\msys64\ucrt64\bin`

## Program

The `hello.c` program prints:

Hello, World!

## Compile Command

`gcc hello.c -o hello.exe`

## Run Command

`.\hello.exe`

## Output

Hello, World!
